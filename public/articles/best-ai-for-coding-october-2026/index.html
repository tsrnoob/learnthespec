The one current board

One public board still scores the models people are using now. It scores the model and the harness it runs in as a single result. Two models released in late September took first and second.

Terminal-Bench — 66 tasks run in a real terminal with no graphical interface. The agent writes and debugs code, configures environments and recovers from its own failures. Every score carries a 95% confidence interval.1

Agent — the harness the model runs inside. It reads files, picks the next command and feeds the result back. The same model scores differently in different harnesses, which is why all 23 rows name both.

Anthropic holds first and second. Third is a tie.

SWE-bench Verified

The benchmark most often quoted for coding has not scored a current model since February. Every entry in its top ten pairs a model with a third-party agent rather than a vendor's own tool.

SWE-bench Verified — 500 real GitHub issues, filtered by human annotators so that each one has a clear problem description, a correct test patch and a solvable fix. A model scores by producing a patch that passes the repository's own tests.3

Its top entry is a Claude 4.5 model. Every flagship released since is missing.

Price per million tokens

Coding spends output tokens. Long diffs, whole files, repeated retries.

Input tokens are the code and instructions you send. Output tokens are the patches, explanations and commands the model writes back. One token runs about 3 to 4 characters of English.

Output costs four to five times input at every vendor here.

The harness you run it in

Terminal-Bench scores the model and the harness as one result, because the harness reads the files and runs the commands.

MCP, the Model Context Protocol, is the open standard these tools use to reach outside data such as Drive, Jira or Slack. Claude Code and Codex both implement it, and the board's top 5 rows all run in one of those two.1617

Claude Code “reads your codebase, edits files, runs commands, and integrates with your development tools”.16 Codex CLI puts permission in front, with a command that sets when it may edit or run unasked.17
