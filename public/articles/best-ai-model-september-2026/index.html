Price per million tokens

Every vendor bills the same way. You pay per token, and input and output are priced separately.

Token — the unit of text a model reads and writes. One token runs about three to four English characters.21 Input tokens are what you send. Output tokens are what the model returns. Output always costs more, between two and six times more across this table.

The spread is wide. GPT-6 Astra output costs over forty times DeepSeek's peak rate, and over eighty times its off-peak rate.

Cost per task

List price does not tell you what a job costs. A model that thinks longer burns more tokens on the same question, so a cheap rate can produce an expensive bill.

Cost per task — the API spend to complete one average task from the benchmark suite. It folds the price, the reasoning tokens and the answer tokens into a single number.2

The ranking changes completely. Claude Opus 5.5 costs forty-six times what MiMo-V2.6-Pro costs to do the same work, for twelve more points of intelligence.

Token efficiency

Two models can reach the same answer and spend very different amounts of text getting there. That difference is what you pay for.

Token efficiency — the total output tokens a model generates to finish all ten evaluations in the index. Lower means it reaches the answer with less writing. Across these eleven models the count runs from 60M to 260M.2

GPT-6 Astra is the efficient one. Claude Opus 5.5 spends more than four times as many tokens on the same suite, and buys five more index points with them.

Context window

Seven of the nine hold one million tokens. Grok 4.7 holds half that.

Context window — how much text the model can hold in mind at once, counting your input and its own output together. One million tokens is roughly 1,500 A4 pages.14

Context is no longer what separates the top of this table from the bottom. It was in 2025. It is not now.

Agent tools and local files

Benchmarks measure answers. Most real work needs the model to take actions: open files, run commands, use tools. This is where the nine separate hardest.

Agentic — the model does not only reply, it acts. It reads and edits files, runs shell commands, and calls external tools. MCP, the Model Context Protocol, is the open standard for connecting those tools to data sources such as Drive, Jira or Slack.22

Three vendors ship a first-party agent, and each gates the filesystem differently.222324 Four publish weights instead, so self-hosting removes the gate.

Open weights

Four of the nine let you download the model and run it yourself. That changes the cost structure and removes the vendor from the loop entirely.

Open weights — the trained model file is published, so you can run it on your own hardware. No API fee, no rate limit, no data leaving your network. You pay for the machine instead. MiMo-V2.6-Pro is a 1.0T-parameter model with 42B active, so the machine has to be a large one.8

MiMo-V2.6-Pro is the highest-scoring of the four, twelve points below the overall leader.8 That is the best score available to anyone willing to host it themselves. Two of the four ship under their publisher's own licence rather than an established open one, and those licences restrict commercial use.911
