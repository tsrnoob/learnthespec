What a cache hit costs

Most requests resend the same opening text: a system prompt, tool definitions, a long document. Every vendor here bills that repeat at a lower rate.

Token — the unit APIs bill by. Anthropic puts one token at about 4 characters, or 0.75 words, of English.1

Prompt caching — the vendor stores the processed opening of a prompt and reuses it when the next request starts the same way. A cache hit is input served from that store. A cache miss is input processed from scratch. Anthropic bills a hit at 0.1 times the normal input price.2

The discount is not uniform. DeepSeek bills a hit at a fiftieth of its full input price, and xAI at a quarter.57

What writing to the cache costs

A cheap hit can come with a charge for creating the cache, or for keeping it.

Cache write — the first request that stores a prompt's opening. Anthropic bills it at 1.25 times the input price for a 5-minute cache and 2 times for a 1-hour cache.2

Three of the seven charge to write or to store. The other four name no such fee on the pages read.

Prices with a clock or a date

Two vendors change the price by time. DeepSeek halves its rates outside peak hours, and Google doubles Gemini 3.8 Flash from the start of 2027.53

Off-peak pricing — a lower rate for requests sent outside set hours. DeepSeek's peak hours are 01:00 to 04:00 and 06:00 to 10:00 UTC, Monday to Friday. Every other hour bills at half.5

The cache rate moves with the base rate, so the share stays the same in every row.

Batch discounts

A batch request trades speed for price. You submit the job and collect the answers later.

Batch API — an endpoint that queues requests and returns the results later, at a lower rate. Anthropic's takes 50% off both input and output tokens.1

Half price is the common rate. Grok 4.6 gets no batch discount, and DeepSeek lists none.85

Long prompts cost more to cache

Two vendors raise every rate once a prompt passes 200,000 tokens, the cached rate included.37

Which one to pick

There is no single cheapest cache. The right one depends on how often your prompt repeats and how long you can wait.
