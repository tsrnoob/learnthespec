MCP: What Actually Connects to What, September 2026

One open standard wires AI applications to your files, databases and tools. Every client implements a different piece of it, including the company that wrote it.
Tsrnoob 5 SEPTEMBER 2026 COMPILED FROM 7 SOURCES CHECKED 5 SEP 2026

One port, many shapes

Before MCP, every AI application needed its own integration for every tool. The standard replaces that with one socket.

MCP — the Model Context Protocol, an open standard for connecting AI applications to external systems. Its own documentation compares it to a USB-C port: one connector shape, so a tool is built once and works everywhere.1

The comparison is good and slightly generous. A USB-C port either fits or it does not.

Three things a server offers

The protocol is small. A server exposes three kinds of thing, and a client may offer one back.

Tools are functions the model can call. Resources are data it can read. Prompts are reusable templates. Going the other way, elicitation lets a server ask the user a question mid-task.2

Two client features were dropped in the current specification. Sampling and logging are both deprecated as of protocol version 2026-07-28, with new implementations told to call model providers directly or log to stderr instead.2

Even the author does not implement all of it

Anthropic wrote MCP. Anthropic's connector documentation carries a note telling builders that its authentication support differs from the generic specification in important ways, and a list of protocol features not yet supported.7

That is not a criticism. It is the normal state of a young standard, and it is the reason to read the client's page rather than the spec's.

Two transports, and a third on the way out

Where the server runs decides how it talks. Seven servers are maintained as reference implementations; everything else comes from a separate community registry.3

How a client reaches a server
TransportUsed forDetailSrc
stdioLocal, same machineStandard input and output between processes. No network overhead. Typically serves one client.[2]
Streamable HTTPRemoteHTTP POST with optional server-sent events. Bearer tokens, API keys or custom headers; OAuth recommended. Typically serves many clients.[2]
HTTP+SSELegacyStill accepted by Claude, being deprecated in favour of Streamable HTTP.[7]

THE OFFICIAL REFERENCE SERVERS ARE SEVEN: EVERYTHING, FETCH, FILESYSTEM, GIT, MEMORY, SEQUENTIAL THINKING AND TIME. THE GITHUB, AWS AND POSTGRESQL SERVERS WERE MOVED OUT OF THAT SET INTO AN ARCHIVE, WITH COMMUNITY SERVERS NOW LISTED IN A SEPARATE REGISTRY.

A local server runs as you

This is the sentence in the specification worth reading twice. A local MCP server is a binary downloaded and executed on your machine, with the client's privileges.4

Confused deputy — an attack where something trusted is tricked into acting for someone else. In MCP it lets an attacker obtain authorization codes without the user ever seeing a consent screen, by reusing a consent cookie set on an earlier legitimate visit.4

The specification answers with obligations rather than advice.

What the specification requires, in its own words
RuleOn whomLevelSrc
Never accept a token not issued for youServersMUST NOT[4]
Never treat holding a state handle as authenticationServersMUST NOT[4]

Show the exact command, untruncated, before one-click installClientsMUST[4]
Reject javascript:, data:, file: and vbscript: URLsClientsMUST[4]
Never open a URL through a shellClientsMUST NOT[4]
Block private and link-local IP ranges when fetching OAuth URLsClientsSHOULD[4]

THE SPECIFICATION ALSO TELLS CLIENTS TO WARN THAT MCP SERVERS RUN WITH THE SAME PRIVILEGES AS THE CLIENT, AND TO SANDBOX THEM WITH MINIMAL DEFAULT PRIVILEGES. THAT IS GUIDANCE, NOT A REQUIREMENT, WHICH IS WHY IT IS WORTH CHECKING YOURSELF.

What to check before installing one

The protocol is open, so anyone can publish a server. Treat one like any other program you are about to run.

Recommendation by use case
If youDoWhy
Want files, git or web fetchUse a reference serverSeven are maintained by the steering group. Filesystem, Git and Fetch cover most of what people install a server for.
Are connecting a remote servicePrefer Streamable HTTP with OAuthThe legacy HTTP+SSE transport is being deprecated, and OAuth is what the spec recommends.
Are building for ChatGPTImplement search and fetchDeep research requires that compatibility schema by name, not the general tool interface.
Are returning big query resultsCheck the size cap firstClaude cuts at roughly 150,000 characters on the desktop surface, 25,000 tokens in Claude Code.
Are offered a one-click installRead the commandThe client must show it untruncated. That is the only moment you see what will run as you.
Assume the spec is the contractRead the client's pageEvery client implements a subset, including the one written by the protocol's author.
