AI Agent Permissions, Compared, November 2026

Five agents edit files and run commands for you, and no two vendors divide the controls the same way: the modes each one publishes, what runs without asking, and the two boundary failures that carry a published score.
Tsrnoob 1 NOVEMBER 2026 COMPILED FROM 9 SOURCES CHECKED 1 NOV 2026

How many settings each publishes

The controls have no shared vocabulary. One vendor's mode is another's preset, and a third splits the same decision across two settings.

Permission mode — a whole-session setting that decides which actions stop and ask you. Claude Code publishes six, and the strictest of them, dontAsk, denies every call that would otherwise prompt.1

The counts do not line up, and that is the result. Codex splits the decision in two, Antigravity publishes one scale for its app and another for its CLI, and Meta publishes no session setting at all.

Allow, ask and deny

Three of the five let you write the rules yourself, in lists you keep in a file. The precedence is the same wherever it is published.

Deny rule — a rule that blocks a tool or a command outright. In Claude Code a deny at any settings level beats an allow at every other level. A managed deny cannot be overridden at all.1

Nobody lets an allow win. Copilot CLI states that a deny holds even with its allow-all flag set and even over an approval you already saved.

COPILOT CLI'S FOUR LISTS ARE --allow-tool, --deny-tool, --allow-url AND --deny-url; THE PAGE NAMES TWELVE PERMISSION FLAGS IN ALL AND FOUR RULE SHAPES. CLAUDE CODE'S AND ANTIGRAVITY'S THREE ARE ALLOW, ASK AND DENY. MUSE'S THREE ARE A DIFFERENT KIND OF THING. THEY ARE A LEVEL PER APPLICATION RATHER THAN A LIST OF TOOLS, SO THE 3 IN ITS ROW DOES NOT MEAN WHAT THE 3 ABOVE IT MEANS. CODEX ADDS WRITABLE DIRECTORIES THROUGH writable_roots, WHICH IS A SCOPE AND NOT AN ALLOW OR DENY LIST.

The setting that removes the boundary

All five ship one setting that turns the whole system off. Three of them warn you about it on the same page.

The widest setting each one publishes, and what it removes

EVERY ROW IS A SETTING THE VENDOR DOCUMENTS ITSELF, NOT A WORKAROUND. ONLY MUSE'S WIDEST SETTING IS SCOPED TO ONE APPLICATION; THE OTHER FOUR APPLY TO THE WHOLE SESSION. CLAUDE CODE KEEPS A SHORT LIST OF ACTIONS THAT NO MODE AUTO-APPROVES, SO bypassPermissions IS NOT TOTAL.

When the boundary failed

Two failures this autumn were published with figures attached. Neither was a permission setting working wrongly.

CVSS — a published severity score from 0 to 10. The same flaw carries two of them, because version 3.1 and version 4.0 score it differently: CVE-2026-111322 reads 9.8 on one and 9.3 on the other.8

One shipped a dangerous default on a public address. The other arrived through the marketplace that distributes the extension.

Which one to pick

There is no single winner. The right agent depends on how much of the decision you want to keep.

Recommendation by use case
If youPickWhy
Want the finest controlClaude CodeSix session modes and three rule lists, and a deny rule at any level beats an allow at every other one.
Want the limit enforced below the modelCodexThe sandbox level is set separately from the approval policy, so the technical boundary survives a bad approval.
Want one switch per projectAntigravityFour presets move the sandbox, the terminal, file access and web access together.
