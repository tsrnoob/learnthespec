AI Jargon, Defined, September 2026

Twenty-five terms, each with the number attached. A definition that carries no figure is decoration, so none here does.
Tsrnoob 5 SEPTEMBER 2026 COMPILED FROM 12 SOURCES CHECKED 1 NOV 2026

Start with the unit

Almost every other term on this page is built on one. Models do not read words and they do not charge by the word.

Token — the smallest unit a model reads and writes. It can be a word, part of a word, a character or a byte. Anthropic puts one token at approximately 3.5 English characters, varying by language.1

Price, speed, context and efficiency are all counted in these. Get the unit wrong and every figure downstream is wrong with it.

What you are billed for
TermDefinition, with the figureSrc
TokenThe smallest unit a model reads and writes. About 3.5 English characters for Claude.[1]
Input tokensEverything you send: the prompt, the conversation so far, any attached documents.[1]
Output tokensEverything the model writes back. Priced separately from input, and always higher.[2]
Reasoning tokensWorking-out the model generates before answering. Not visible via the API, occupy the context window, and billed as output tokens.[2]
Context windowThe working memory: how much text the model can look back on while generating. Distinct from what it was trained on.[1]
Token efficiencyHow many output tokens a model spends finishing the same work. Measured as the tokens burned running one identical benchmark suite.[3]

REASONING TOKENS ARE THE ONE MOST PEOPLE MISS. YOU PAY FOR TEXT YOU NEVER SEE, WHICH IS WHY TWO MODELS AT THE SAME PUBLISHED RATE CAN PRODUCE VERY DIFFERENT BILLS.

Two numbers for speed, not one

Every comparison quotes tokens per second. That is the second half of the wait.

How fast it is, and how good it is
TermDefinition, with the figureSrc
Time to first tokenSeconds between sending a request and receiving the first token back.[1][4]
Output speedAverage tokens received per second after the first token arrives.[4]
LatencyThe delay between submitting a prompt and receiving the output. Moves with model size, hardware, network and prompt complexity.[1]
BenchmarkA fixed task set plus a marking rule. Change either half and the number changes.[5]
Intelligence IndexA composite, currently v5.0: nine evaluations in four categories, knowledge work, coding, science and general, weighted at 25% each.[5]
Arena EloA rating fitted from blind pairwise votes by Bradley-Terry maximum likelihood, then anchored by fixing one model at 1000.[6]

AN ELO OF 1200 MEANS NOTHING ALONE. IT MEANS "BEATS THE ANCHOR MORE OFTEN THAN NOT", AND THE ANCHOR IS A CHOICE. ONLY THE GAPS BETWEEN MODELS CARRY INFORMATION.

Open weights is not open source

These two get used interchangeably and mean different things. One is a download. The other is a definition with a version number.

Open Source AI Definition 1.0 — the OSI standard. It requires the freedoms to use, study, modify and share, and all three of data information, complete training and inference code, and the model parameters, each under OSI-approved terms.7

Downloadable weights satisfy one of those three components. Most models described as open are open-weight, not open source, and the distinction decides what you are allowed to rebuild.

What you can run yourself
TermDefinition, with the figureSrc
Open weightsThe trained parameters are downloadable. One of the three components OSI requires, on its own.[7]
Open source AIAll four freedoms plus data information, code and parameters. Version 1.0 of the definition.[7]
QuantisationStoring weights at lower precision. An int8 model is roughly 4× smaller than float32; int4 halves it again, mapping to 16 possible values.[8]
VRAMMemory on the graphics card itself. A model has to fit inside it to run at full speed.[9]
CUDA and ROCmThe compute stacks local tools reach a GPU through. Ollama asks CUDA capability 5.0 and driver 550 for NVIDIA, ROCm v7 for AMD.[9]

QUANTISATION IS WHY A MODEL TOO LARGE FOR YOUR CARD AT FULL PRECISION OFTEN FITS AT INT4. THE COST IS ACCURACY, AND IT IS LARGER AT INT4 THAN AT INT8.

The words for reaching outside the chat

Anthropic draws the line between an agent and a workflow at who decides the next step.

What it can reach
TermDefinition, with the figureSrc
Agentic systemThe umbrella term covering both workflows and agents.[10]
WorkflowModels and tools orchestrated through predefined code paths. The route is fixed by the developer.[10]
AgentModels that dynamically direct their own processes and tool usage, keeping control of how a task gets done.[10]
Computer useA tool letting a model control a real interface by coordinate rather than returning text. Anthropic's version exposes 17 actions.[11]
MCPAn open protocol standardising how applications supply context to models. Its own docs call it a USB-C port for AI applications.[1]
Tools, resources, promptsThe three things an MCP server can expose: functions to call, data to read, templates to reuse.[12]
Prompt injectionInstructions hidden in content the model reads. Anthropic states plainly that a model will sometimes follow them over yours.[11]
RAGRetrieval augmented generation: fetching documents at query time and passing them into the context window, rather than relying on training.[1]

THE AGENT AND WORKFLOW DISTINCTION IS NOT MARKETING. A WORKFLOW FAILS PREDICTABLY BECAUSE ITS ROUTE IS FIXED; AN AGENT CAN TAKE A PATH NOBODY WROTE DOWN, WHICH IS BOTH THE POINT AND THE RISK.

Three of these changed this year

A glossary of a moving field dates in a specific way: the word survives and the thing underneath it does not.

The Intelligence Index is on version 5.0, so scores published under earlier versions measure something else.5 MCP deprecated two of its client primitives, sampling and logging, in specification version 2026-07-28.12 The Open Source AI Definition carries a version number for the same reason.7

Check the version before quoting any of the three.

Which term to look up when

Each of these is the one that decides the answer.

Recommendation by use case
If youLook upBecause
Are comparing pricesReasoning tokensThe advertised rate is one of two numbers. The other is how much the model writes to itself.
Are picking for chatTime to first tokenIn a conversation you feel the first wait, not the tokens per second after it.
Are picking for long documentsOutput speedOnce generation starts, this is the only number you experience.
Are reading a leaderboardIntelligence IndexIt is a weighted average of ten tests, not a measurement. Coding is a fifth of it.
Are told a model is openOpen source AI 1.0Downloadable weights are one of three required components, not all of them.
Are installing a connectorPrompt injectionAn MCP server runs with your privileges, and screen content is not trusted input.
