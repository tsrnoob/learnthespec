What Reasoning Effort Costs, November 2026

Six vendors let you set how hard a model thinks, and no two name the levels alike: what each level scores, what it costs, and where the top setting buys less than the one below.
Tsrnoob 8 NOVEMBER 2026 COMPILED FROM 10 SOURCES CHECKED 8 NOV 2026

Who publishes an effort setting

Six vendors let the caller decide how long a model thinks before it answers.3

Reasoning effort — one request parameter that tells a model how much thinking to spend before it replies. Anthropic's own documentation calls it “a behavioral signal, not a strict token budget”, and publishes five levels: low, medium, high, xhigh and max.3

No two of the six publish the same ladder. Two say in writing that thinking cannot be switched off at all.79

A level name says nothing about what it buys. One board scores the same model at each of its own levels, which is what makes the ladder visible.

Intelligence Index — Artificial Analysis's weighted average of nine evaluations in four categories, each category weighted at 25%, at version v5.0.1. Scores from two index versions are not comparable, so every figure below comes from one read of one board.2

A level name costs nothing. The tokens it spends do, and the board prices the whole run.

Cost per task — the money spent running one Intelligence Index task. The token counts come from each provider's own API, priced at that model's measured cache hit rate.2

The ranking does not survive the switch. The dearest single cell belongs to a model outside the top three on score, and the cheapest ladder is the one that scores lowest at every level.1

What the default costs you

Most requests never set the parameter at all. The vendor's documented default then decides, and only two of the six default to their own top setting.89

The default is rarely the top. On one Claude flagship the top setting costs four times the default, for a score the same model reaches nowhere else.1

How long you wait

Effort buys thinking, and thinking takes wall-clock time. The board times both the start of the reply and the whole task.

Time to first answer token — the seconds between the request being sent and the first token of the reply arriving. The board prints one reading per row rather than an average over runs, and ranks Claude Opus 5.5 at max 57th of 68 models on it.10

Latency rises much faster than score. The slowest start here is almost sixty times its own model's quickest, for a score that climbs by about two thirds.1

Which one to pick

There is no single right level. The right one depends on whether you are paying per task, waiting for the reply, or neither.
