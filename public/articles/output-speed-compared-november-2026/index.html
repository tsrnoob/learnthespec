Output Speed, Compared, November 2026

The public board now times a whole task instead of printing tokens per second. Here is how long each leading model takes, how long it waits before answering, and what an effort step or a paid fast tier changes.
Tsrnoob 25 NOVEMBER 2026 COMPILED FROM 8 SOURCES CHECKED 25 NOV 2026

Time per task

Among the ten highest-scoring models, the slowest takes four times as long per task as the fastest.1

Time per task — the minutes a model takes to finish one average Intelligence Index task. Artificial Analysis computes it as output tokens divided by end-to-end output speed, and gives 12.4 minutes as the median for comparable models.2

Two waits, not one

A task time says when the work is done. It does not say when the answer starts.

Time to first answer token — the seconds before the first token of the answer arrives, with the model's thinking time counted. Claude Opus 5.5 at max effort reads 337.81 seconds on the board.12

The three longest waits in the table all belong to Claude models. The model that finishes a task fastest is not the one that answers first.1

Effort sets the time

The same model has a different task time at each effort level.

Reasoning effort — a setting for how long a model thinks before it answers. GPT-6.2 Astra has five levels on its Artificial Analysis page, from low to max.2

Astra's xhigh level scores the same as max in a little over half the time. The writing speed barely moves.2

Tokens per second

The September edition ranked on this figure. The model pages still print it, one model at a time.

Output speed — tokens written per second. Artificial Analysis counts it as output tokens divided by total request time, including the time to first token.2

Both Claude models write more than twice as fast as GPT-6.2 Astra and still take longer per task. The gap is in how many tokens each one spends.
