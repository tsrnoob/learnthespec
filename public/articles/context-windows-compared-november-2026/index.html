Context Windows, Compared Honestly, November 2026

Most current flagships list about a million tokens of context. What differs is how long one reply can be, where the price steps up, and how much of the window a chat app hands over.
Tsrnoob 25 NOVEMBER 2026 COMPILED FROM 18 SOURCES CHECKED 25 NOV 2026

What each vendor lists

Nine of these ten models list about a million tokens of context, and their reply limits spread nearly eightfold.713

Context window — the most tokens a model can hold in one request, counting the prompt, its reasoning and its reply. Google gives the Gemini 4 window as 1,048,576 tokens, one limit shared by input and output.7

The longest single reply

The reply limit decides whether a long job finishes in one call.

Max output — the most tokens a model writes in one reply, a limit set apart from the window. Anthropic lists 128K for every current Claude model against a 1M window.1

Google has the lowest default in the first table and the highest ceiling. The route between the two has rules of its own.8

Long decode — Google's name for raising a Gemini 4 reply past 65,536 tokens. Generation runs as a chain of hops of up to 65,536 tokens each, joined into one response.8

Token length is not fixed

Windows are counted in tokens, and the same text is not the same number of tokens everywhere.

Tokenizer — the rule that cuts text into tokens. Anthropic states that Claude 4.7 and later models use a newer one that produces approximately 30% more tokens for the same text.3

So a window of the same size holds less text on the newer Claude models than on the older ones. Artificial Analysis fixes one tokenizer, cl100k_base, to measure document length in the test below.15

Reasoning across long documents

Holding a document is not the same as reasoning across it. One public test measures the second.

AA-LCR v1.1 — Artificial Analysis's long-context reasoning test. 100 questions over documents of 10,000 to 100,000 tokens, where the answer has to be assembled from several sections.15

The longest document in the test is a tenth of the windows above. Artificial Analysis now labels the test Legacy.15

Context costs memory

On your own machine the window is paid for in GPU memory. One model card prints the trade at three file sizes.17

A smaller file leaves more room for context. The full window still does not fit a 24 GB card at any of the three.

There is no single winner. The window is the figure these models share, so pick on the ones they do not.
