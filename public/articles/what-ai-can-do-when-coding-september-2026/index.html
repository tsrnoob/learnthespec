What AI Can Actually Do When You Code, September 2026

Autocomplete was five years ago. These tools now read a whole repository, edit files, run your tests, open pull requests and work while your laptop is shut. Here is the full capability list, and what each one is allowed to touch.

Reading the codebase

The single change that separates these tools from autocomplete. You describe a problem; the tool finds the relevant files itself.

Agentic loop — the tool reads files, decides what to do next, acts, then reads the result and repeats. Claude Code “reads your codebase, edits files, runs commands, and integrates with your development tools”.1 Codex “inspects code, makes changes, runs commands” from the terminal.2

You stop pasting snippets. That is the whole shift.

Editing many files at once

A rename that touches forty files, a migration, a dependency bump. All five tools do multi-file edits; Copilot calls its version agent mode, where it “autonomously determines which files to modify and suggests changes for user approval”.9

Running commands and tests

The tool can run your test suite, read the failures, and fix them without being told what broke.

This is the capability that turns suggestions into finished work. It is also the one that needs a boundary, which is why every vendor has an opinion about sandboxing.

Commits and pull requests

Claude Code “stages changes, writes commit messages, creates branches, and opens pull requests”.1 Copilot's cloud agent “can research a repository, create an implementation plan, and make code changes on a branch”, and you assign it an issue directly.9

Codex cloud goes further on entry points: you can start a task from the web, GitHub, GitLab, Linear or Slack.4

Working in parallel

Three tools split work across several agents at once, and they solve the collision problem differently.

Subagent — a second copy of the agent given part of the task, with a lead agent coordinating and merging results.1 Git worktree — a separate checkout of the same repository, so two agents editing at once never touch the same working directory. Antigravity uses worktree isolation for this.7

Codex takes the third route and runs each task in its own cloud environment, which sidesteps local collisions entirely.4

Working while you are away

Every tool here except Cursor can run without you watching.

Claude Code splits this in two: Routines run in the cloud “so they keep running even when your computer is off”, while desktop scheduled tasks run on your machine with access to local files.1 Codex cloud runs tasks in isolated environments in parallel.4 Antigravity's CLI supports headless mode and background tasks.7

Telling it your rules

A file in your repository that the tool reads before it starts. Build commands, test commands, code style, things not to touch.

AGENTS.md — “a README for agents: a dedicated, predictable place to provide the context and instructions to help AI coding agents work on your project”. Used by over 60,000 open-source projects and now stewarded by the Agentic AI Foundation under the Linux Foundation.10 Anthropic's equivalent is CLAUDE.md.1

One file, read by Codex, Copilot's coding agent, Cursor, VS Code, Gemini CLI, Zed, Aider, Devin, Windsurf and Junie.10 It is the closest thing this field has to a standard.

Connecting your other tools

The agent can reach outside the repository — a ticket tracker, a design doc, a database.

MCP, the Model Context Protocol, is the open standard for connecting AI tools to external data sources. With it an agent can read design docs in Drive, update tickets in Jira, or pull data from Slack.1

Driving a browser

Two tools debug a running web app rather than just its source. Claude Code integrates with Chrome to debug live web applications.1 Antigravity ships explicit browser debugging in Chrome.7

The agent loads the page, reproduces the bug, and fixes it. No screenshot pasting.

What still does not work

Three limits, all published rather than observed.

It is not finishing most tasks. The best model and agent pairing resolves 58.2% of Terminal-Bench 4.0's 66 real terminal tasks.11 Two in five still fail.

The agent is only half the result. Terminal-Bench scores model and harness together, which is why the same model places differently in different tools.11 Switching tools changes your outcome even on the same model.

Autonomy costs oversight. Codex's own documentation is explicit that the sandbox exists so the agent can “act autonomously without giving it unrestricted access to your machine”.3 Full access is available and named danger-full-access. The name is the warning.
