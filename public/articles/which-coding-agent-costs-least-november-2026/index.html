Which Coding Agent Costs Least, November 2026

One benchmark ran twenty-two coding agents on the same five models and the same sixty-two tasks, so for once the agent can be priced with the model held still.
Tsrnoob 22 NOVEMBER 2026 COMPILED FROM 11 SOURCES CHECKED 22 NOV 2026

The agents on this page

Every one of these runs the model you choose, at its own default settings.1

Harness — the program that runs the model. It sends the prompt, reads the reply, runs the commands the model asks for and sends the result back. One finished task took between 24.8 and 73.5 of those exchanges, depending on which harness ran it.1

The cheapest agent finished a job for little more than half what the dearest one charged. The pass rates sit much closer together.

What the five models cost

The agent's bill is mostly the model's bill, so the models have to be named before anything else.

Cost per pass — the average cost of a task divided by the share of tasks that passed. At a pass rate of one half, a task that costs a dollar to attempt costs two dollars to finish.1

List prices across the five span twenty times or more. The cache carries almost all of the input.

The model sets the level of the cost and the agent sets the rest. The rest is not small.

What makes an agent expensive

A lean prompt and a short tool list are the things an agent advertises. Neither one predicts what it costs.

Step — one entry in the agent's trajectory: one request to the model and the result of whatever it asked for. Each step sends the whole conversation again, so one trial sent between 2.0 and 4.8 million input tokens.1

Three of the four do not move with cost at all.

Where the money goes

Most of the spend on this board bought nothing.

Reward hacking — passing the check without doing the task, for instance by looking the answer up online or reading the grader's own files. The audit flagged 216 trials, 163 of them online lookups, and scored every one zero.1

Nearly two thirds of the bill went to runs that did not pass. Most of those failures ended with the agent saying it was finished.
