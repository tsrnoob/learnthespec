Every AI Benchmark, Explained, September 2026

Every model announcement leads with a percentage. Here is what each of those tests actually asks, how big it is, and the three ways the number in front of you is not the number you think.
Tsrnoob 5 SEPTEMBER 2026 COMPILED FROM 8 SOURCES CHECKED 27 SEP 2026

A benchmark is a fixed set of questions

Nothing more. Someone writes down a pile of tasks, decides how to mark them, and runs every model through the same pile.

Benchmark — a fixed task set plus a marking rule. Both halves matter equally: the same tasks marked a different way produce a different number, and the same name can cover a task set that has since been rewritten.8

Which is why the useful question is never "what did it score". It is "on what, marked how, and which version".

The Intelligence Index is ten benchmarks in a coat

Most "intelligence" comparisons on this site and elsewhere quote one number. It is an average of ten.

Intelligence Index — Artificial Analysis's composite score, a weighted average across four categories: agents 30%, general 30%, coding 20%, scientific reasoning 20%. Currently at version 4.3.2, made of ten separate evaluations.1

Elo is anchored to an arbitrary model

Image and video rankings do not measure anything absolute. They count who won.

Arena Elo — a rating fitted from blind pairwise votes using Bradley-Terry maximum likelihood, then rescaled to an Elo-like range for readability. In the text-to-image arena the whole scale is pinned by setting one model, FLUX.2 [dev], to exactly 1000.3

So an Elo of 1200 means nothing on its own. It means "beats the anchor more often than not". Only the gaps between models carry information, and the anchor can be changed.

The same name is not the same test

This is the failure that catches everyone, including this site. A benchmark name is not a fixed thing.

Speed is measured, not scored

Two figures on every model page are not benchmarks at all. Nobody marks them right or wrong.

Time to first token — the seconds between sending a request and receiving the first token back. Output speed — the average tokens received per second after that first token arrives.2

Both are stopwatch readings of a live service, so they move with load, region and provider. A benchmark score is repeatable in a way these two never are.

How to read a benchmark claim

Six questions, in the order worth asking them.

What to check before believing a percentage
AskBecause
Which version?Names persist across rewrites. The Index is on v4.3.2, which moved its own coding slot from Terminal-Bench v2.1 to 4.0.
Marked how?Partial against strict moved one model 36 points on identical runs.
Who ran it?Almost every headline figure is self-reported by the vendor selling the model.
Is it a composite?An Index score is a weighted average. Coding is only a fifth of this one.
Absolute or relative?Elo is anchored to a chosen model at 1000. The gap is the signal; the number is not.
Compared against what?OSWorld gives a human baseline of 72.36%. Most benchmarks give none at all.
