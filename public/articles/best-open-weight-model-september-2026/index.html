The leader is also nearly the cheapest

Xiaomi released MiMo-V2.6-Pro on 21 September.4 It takes the top score on the current index.

The two rows below it cost roughly fifteen times as much per task.2 On the index version this page carried before today, the leader was the dearest model in the table.

The cheapest row

List price is not what a job costs, because a verbose model spends more tokens reaching the same answer.

Cost per task — the API spend to complete one average task from the benchmark suite, combining input, reasoning and answer tokens. It applies when you rent the model from a host. Self-host it and this number becomes your hardware bill instead.2

MiMo-V2.6-Flash scores eight points below its Pro sibling and costs less than half as much per task.5 Only gpt-oss-120b runs cheaper than the Pro, and it scores about a quarter as much.12

Total parameters are not running parameters

Kimi K3 is the largest file here. That number does not tell you what it costs to run.

Mixture of experts — only part of the model activates per token. Kimi K3 activates 104 billion of its 2.8 trillion, selecting 16 of 896 experts.1 MiMo-V2.6-Pro activates 42 billion of 1.0 trillion.4 gpt-oss-120b activates 5.1 billion of 117 billion.18

The whole file still has to fit in memory. Activation only decides how much compute each token costs, not how much storage the model needs.

What it takes to run

One publisher states a hardware target outright. OpenAI says gpt-oss-120b is designed to “fit into a single 80GB GPU” such as an H100 or MI300X, using MXFP4 quantisation.18

Nobody else on this list publishes an equivalent figure. The two trillion-parameter models are datacentre models however few experts fire per token.

The gap to closed models

The best open-weight score sits twelve points below the best closed one, Claude Opus 5.5, on the same index version and the same pass.2

The cost comparison runs the other way. Opus 5.5 costs roughly forty-six times what MiMo-V2.6-Pro costs per task.2
