Best Open-Weight Model, September 2026

Seven models you can download and run yourself, compared on intelligence, cost per task, speed, context and licence. The highest score is the slowest and the most expensive, and the most permissive licences sit in the middle of the table.

The seven you can download

Every model here publishes its weights on Hugging Face. Every figure comes from Artificial Analysis, measured on the same index version in the same pass.

Open weights — the trained model file is published, so you can run it on your own hardware with no API fee and no rate limit. It is not the same as open source, which additionally requires training code and data information.10

The leader is the slowest

Kimi K3 takes the top score at 50. It is also the slowest model in the table at 39.6 tokens per second, and the most expensive per task at $1.58.3

gpt-oss-120b sits at the other end on every axis: last on intelligence at 16, first on speed at 162.9, and cheapest at $0.12.9 Four times the speed of the leader, and a third of its score.

The value pick is not the leader

GLM-5.3-Flash scores 46 against Kimi K3's 50. It costs $0.18 per task against $1.58.53

Four index points, for roughly one ninth of the cost. No other pair in the table trades that steeply.

Cost per task — the API spend to complete one average task from the benchmark suite, combining input, reasoning and answer tokens. It applies when you rent the model from a host. Self-host it and this number becomes your hardware bill instead.2

Total parameters are not running parameters

Kimi K3 is 2.8 trillion parameters. That number does not tell you what it costs to run.

Mixture of experts — only part of the model activates per token. Kimi K3 activates 104 billion of its 2.8 trillion, selecting 16 of 896 experts.1 DeepSeek V4 Pro activates 49 billion of 1.6 trillion.7 gpt-oss-120b activates 5.1 billion of 117 billion.11

The whole file still has to fit in memory. Activation only decides how much compute each token costs, not how much storage the model needs.

What it takes to run

One publisher states a hardware target outright. OpenAI says gpt-oss-120b is designed to “fit into a single 80GB GPU” such as an H100 or MI300X, using MXFP4 quantisation.11

Nobody else on this list publishes an equivalent figure. At 2.8 trillion and 2.4 trillion parameters, Kimi K3 and Qwen3.8 are datacentre models regardless of how few experts fire per token.

The gap to closed models

Kimi K3 at 50 sits seven points below Claude Fable 5.1 at 57, the highest score on the same index.2

The cost comparison runs the other way. Fable 5.1 costs $6.12 per task against Kimi K3's $1.58, and GLM-5.3-Flash's $0.18.25
